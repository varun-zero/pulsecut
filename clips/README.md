# Output clips

This directory holds finalized MP4 shorts generated by the PulseCut pipeline.

No clips are currently stored. Generate new ones from the Dashboard by pasting
a video URL (or importing a local file), or via the API:

```powershell
POST http://127.0.0.1:8756/api/jobs
{ "url": "https://youtu.be/...", "max_clips": 6, "template": "default" }
```

Working downloads and intermediate files live in the git-ignored `out/`
directory and are cleared separately.
